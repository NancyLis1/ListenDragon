# ADR-002：FAISS + BM25 + RRF 混合检索

- 状态：接受
- 日期：2026-09-01
- 决策人：李乐妍（系统工程师）

## 决策

同一组带时间戳的转写分块建立 FAISS 语义索引与 BM25 词项索引。查询可经 LLM 扩展为最多 3 个变体；每路取 Top-8，采用 Reciprocal Rank Fusion（默认 k=60）融合、去重后向生成模型提供 Top-6。

## 理由

语义检索处理同义表达，BM25 保留人名、术语和数字等精确匹配；RRF 不要求不同分数空间可比，适合短周期 MVP。

## 质量约束

回答必须携带 `[mm:ss-mm:ss]` 引用；无足够证据时返回“视频中未找到依据”，不得脱离检索上下文编造。
