# ADR-001：模块化单体与独立 Worker

- 状态：接受
- 日期：2026-09-01
- 决策人：李乐妍（系统工程师）

## 背景

项目周期短、团队 5 人、主要运行环境为笔记本。视频处理是长耗时任务，但当前没有运维 Redis、消息队列和多服务集群的资源。

## 决策

采用单一代码仓库和模块化单体后端；API 与 Worker 使用同一镜像、不同进程。SQLite 任务表保存状态，Worker 以租约方式领取任务。前端单独构建为静态站点。

## 后果

- 优点：部署面小、调试链短、失败可恢复、后续可把 Worker 拆为服务。
- 代价：单机吞吐有限；MVP 将 Worker 并发限制为 1。
- 演进触发器：任务积压持续超过 10 个或需要多机扩容时，迁移 PostgreSQL + Redis 队列。
